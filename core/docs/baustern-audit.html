2. Чего не хватает

По убыванию влияния на заявки. Первые два пункта важнее всего дизайна вместе взятого.

2.1

Сайт индексируется как одна страница

Роутер работает на #/…. Для Google адрес baustern.ch/#/wissen/badsanierung-kosten-zuerich-2026 — это просто baustern.ch. Все детальные страницы Leistungen, три региональные страницы «Sanierung Zug/Winterthur/Luzern», четыре статьи Wissen, кейсы — написаны под SEO и невидимы для поиска. Это самая дорогая дыра на сайте: контент есть, трафика с него не будет.

Решение: перевести роутер на обычные пути (History API) + Netlify _redirects уже лежит + пререндер при деплое (скрипт на Playwright генерирует статический HTML для каждого из ~30 роутов). Ссылки и data-go уже централизованы в goPath(), так что переезд контролируемый. Оценка: 1–2 дня. Sitemap тогда станет настоящим.

2.2

Нет никакой аналитики — вы летите вслепую

Ни один клик не измеряется: не видно, доходят ли люди до калькулятора, что выбирают в сегментах «Ich bin…», где бросают форму (9 полей), работает ли «Rückruf in 5 Min». Всё, что мы делали по дизайну, нельзя проверить цифрами.

Решение: Plausible или Umami (без cookies, совместимо с nDSG, баннер не нужен) + 6 событий: Offerte-клик, Rückruf, Rechner-использование, Segment-выбор, Form-submit, Lightbox-открытие. 2 часа.

2.3

«Wissen & Ratgeber»: 9 тем, 4 статьи

Пять позиций в списке ведут на «Frage stellen» — это выглядит как пустой раздел, и именно те темы, по которым ищут («Was kostet eine Renovation in Zürich?», «Sanitärnotfall»), без статьи. Данные для первой статьи у вас уже есть — диапазоны из калькулятора.

Решение: дописать 3 самые поисковые темы (по 400–600 слов, из ваших данных), остальные две убрать из списка до готовности. Без пререндера (2.1) статьи всё равно не найдут — делать в паре.

2.4

Доказательства доверия наполовину пустые

Google 4.6 (12) и Renovero 4.3 (33) показаны — хорошо. Но: полоса логотипов клиентов в коде стоит как [PLATZHALTER] и не выводится; «Versichert» без конкретики (Haftpflicht на какую сумму, SUVA); «Werkgarantie 24 Monate» нигде не расписана, что покрывает; на детальных страницах Leistungen нет ни одного «до/после» (они есть только на главной, в туре).

Решение: 3–5 логотипов Verwaltungen/GU с их согласия; одна строка про страховку с суммой; блок «Vorher/Nachher» на Leistungen-детали из уже существующих фото (Rückblende-кадры есть). Нужны от вас: согласия и цифра страховки.

2.5

Телефон получает сайт «второго сорта»

На десктопе: видео-интро, тур по квартире, Bauplan-массетки, стеклянные листы. На телефоне: статичные кадры + текст, без тура, без Bauplan, без HUD. Для B2B-сайта 40–60 % визитов с телефона (Verwaltung смотрит с телефона на объекте). Разрыв заметен.

Решение: мобильный «Rundgang» как горизонтальный свайп по семи стоп-кадрам с подписями Gewerke (без канваса и видео — дёшево и быстро). 1 день.

2.6

Калькулятор только на главной

Самый сильный конверсионный элемент («Richtwerte in 30 Sekunden») живёт на одном листе тура. На страницах Leistungen/Sanitär или Renovation — где намерение выше всего — его нет.

Решение: тот же .est-компонент с предвыбранным Gewerk на каждой Leistungen-детали. 3 часа.

3. Что выглядит слабее, чем могло бы

Не баги — вкус и последовательность. Честно, без «всё отлично».

Старые карточки на второстепенных страницах/sanierung-*, /bewertung, /karriere, 404 всё ещё на белых «promise»-карточках с ромбиком. Главная, Leistungen, Lösungen, Über uns уже говорят языком v8 (Datenblatt, индекс, стекло). Разнобой заметен, если ходить по сайту подряд.
Hero на десктопе перегруженОдновременно: ротирующийся кикер, заголовок, абзац, три счётчика, две кнопки, trust-строка, «Rundgang»-подсказка, три хотспота, план, точки. Всё по отдельности хорошее; вместе — плотно. Я бы убрал счётчики из hero (они повторяются в Referenzen) и оставил одну кнопку.
ФутерФункциональный, но плоский: 5 колонок ссылок. Для строительной фирмы там просится одно фото объекта и строчка «Nächste freie Kapazität: KW 40» — живое доказательство, что фирма работает.
Кейсы — 4 штуки, из них 2 «Deutschschweiz»Для Verwaltung в Цюрихе важна география. Если есть ещё объекты в городе — их стоит поднять, даже без полной истории (фото + 3 факта).
Кнопка «Rückruf in 5 Min»Сильное обещание. Если после 18:00 или в воскресенье оно не выполняется, это первый минус-балл. Модал должен показывать «Mo–Fr 07–18: in 5 Min · sonst am nächsten Werktag ab 07:00» в зависимости от времени.
Анимации всегда включеныОсознанное решение проекта («reduced-motion игнорируется»). Тур на 384 кадра для части людей — реальный дискомфорт. Один переключатель «Animation aus» в HUD снимает риск и не трогает дизайн для остальных.

5. Техническое состояние — кратко

ПроизводительностьСкролл по комнатам: медиана 16.7 ms (60 fps), 17 % кадров дольше 33 ms (было 61 %). FCP 188 ms без троттлинга. Первый экран главной ≈ 2.5 MB (1 MB видео-интро + 0.9 MB кадров/фото) — для десктопа нормально; на телефон видео не грузится.
СтекVanilla JS, GSAP + ScrollTrigger + Lenis, без сборки. Шрифты self-hosted. Три внешних вызова: n8n (формы), Supabase (кэш отзывов, только чтение), Calendly/WhatsApp (ссылки). Ключ Supabase anon — публичный по дизайну, RLS на стороне базы должен быть read-only на эту таблицу — проверьте.
ДоступностьФокус видимый, Esc закрывает модал и лайтбокс, tablist сегментов на стрелках, skip-link добавлен, alt у всех изображений, одна H1 на страницу. Открытый вопрос — только reduced-motion (см. §3).
Что не проверялРеальный Safari/iOS (headless Chromium без H.264 — видео-интро играет там через WebM-fallback), реальную отправку в n8n (подменена в тесте), поведение под Cloudflare/DNS после переезда домена с Vercel.
