# Работа с проектом на двух машинах (Windows + Mac)

## Что где лежит

| Что | В гите | Размер | Почему |
|---|---|---|---|
| `site/` html, css, js, vendor | да | ~1 МБ | код сайта |
| `site/img/film/v16/` | да | 180 МБ | актуальные видео и стиллы |
| `site/img/film/` старые версии (r13, r15, m3, v, s1x…) | да | ~240 МБ | ещё встречаются ссылки в коде |
| `site/img/` остальное | да | ~140 МБ | картинки страниц |
| `core/dev`, `core/docs`, `core/sources`, `core/integrations` | да | ~30 МБ | скрипты и документация |
| Все `*.md` в корне (BRIEF, PLAN, HANDOFF…) | да | ~300 КБ | контекст проекта |
| `_work-rife/`, `_work/`, `_stage-film-rife/` | **нет** | 5.2 ГБ | промежуточные рендеры, регенерируются |
| `core/tools/` | **нет** | 860 МБ | rife-ncnn-vulkan, **только Windows** |
| `core/_incoming/` | **нет** | 717 МБ | сырьё для рендера |
| `core/_legacy/`, `core/_backup/` | **нет** | 230 МБ | архив |
| `site/img/film/f13*, f15, fp15` | **нет** | 185 МБ | webp-секвенции, в коде не используются |

Итог репозитория: **~817 МБ, 3404 файла**. Git LFS не нужен — самый большой файл 8.5 МБ, лимит GitHub 100 МБ.

### ⚠️ Одно последствие

В `data.js` активна версия **FILM_V16** (`FILM = ... : FILM_V16`, строка 770). Версии v13 и v15 остались только как rollback через `?film=13` и `?film=15`.

Их webp-секвенции кадров (`f13/`, `f13h/`, `f13l/`, `f15/`, `fp15/` — 185 МБ) в гит **не попадают**. Значит на свежем клоне rollback-URL работать не будут. Боевой сайт (v16) — полностью рабочий.

Если rollback нужен — убери эти пять строк из `.gitignore` и перезапусти `setup-git.ps1`. Репо станет ~1 ГБ.

---

## Шаг 1. Windows: собрать репозиторий

Запусти в папке проекта:

```powershell
.\setup-git.ps1
```

Скрипт сам: создаст репо, добавит файлы, проверит размеры, сделает коммит и запушит на GitHub (спросит URL).

Перед этим создай **пустой приватный** репозиторий на https://github.com/new — без README, без .gitignore, без лицензии.

---

## Шаг 2. Mac: забрать проект

```bash
cd ~/Projects          # или куда удобно
git clone <URL-репозитория> "сайт-ссс"
cd "сайт-ссс"
```

Клон ~600 МБ, несколько минут.

---

## Шаг 3. Mac: запустить сайт локально

Статика, сервер не нужен — достаточно любого http-сервера:

```bash
cd site
python3 -m http.server 8080
```

Открыть http://localhost:8080

---

## Шаг 4. Mac: подключить Claude

1. Поставить Claude Desktop, залогиниться тем же аккаунтом.
2. Создать коворк-сессию.
3. Подключить папку `сайт-ссс`.

Дальше всё как здесь. История чатов синхронится через аккаунт, файлы — через git.

---

## Ежедневный цикл

**Перед работой** (на любой машине):
```bash
git pull
```

**После работы:**
```bash
git add -A
git commit -m "что сделал"
git push
```

Одно правило: не работать на двух машинах одновременно без пуша. Иначе конфликты.

---

## Что НЕ заработает на Маке

- **RIFE-пайплайн** (`core/tools/rife-ncnn-vulkan`) — Windows-бинарник с Vulkan. Рендер видео остаётся на винде. На Маке — код, вёрстка, контент, деплой.
- Скрипты `core/dev/*.cmd` — синтаксис Windows. При необходимости перепишу под bash.

---

## Netlify деплой

`.netlify/` не в гите (локальная привязка). На Маке один раз:

```bash
npm i -g netlify-cli
netlify login
netlify link
```

## Если репозиторий окажется слишком тяжёлым

Можно убрать старые версии видео из `site/img/film/` (r13, r14, m3, v, s1x, mp14, mp15, mat2, mat5) — это ~240 МБ. Сначала нужно проверить, что живые страницы на них не ссылаются: актуальная версия — **v16**.
